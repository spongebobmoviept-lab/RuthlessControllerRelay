Ruthless Controller Relay — What Works Cheat Sheet

Plain-English guide: which controllers work, how well, and why. No tech knowledge needed. For version 1.4.0.

The short version

Best experience: a USB cable for PlayStation controllers, a wireless dongle for Xbox controllers. That way everything works: moving, buttons, vibration, and light color. Bluetooth works great for moving and buttons on every controller, but PlayStation controllers (DualSense / DualShock 4) lose vibration and light color over Bluetooth — see why below. This is not something wrong with your setup, it's true for everyone, everywhere.

⚠ † HOTAS mode does NOT reliably work with a wired Xbox controller
HOTAS mode is the main reason this program exists — and a wired Xbox controller is the one case where it can't be trusted. Windows connects a wired Xbox controller through a special driver that this software (or anything else) has no ability to hide from other apps, unlike every other controller in this list. That means the game can still notice the real controller and use normal gamepad controls instead of reading the joystick axes this program is feeding it through HOTAS mode — the mode may look like it's working on this screen while the game itself ignores it. The same underlying problem also makes V (disguise as PlayStation) and M (button remap) unreliable for this controller.

Fix: connect that Xbox controller through a wireless dongle instead of a cable (the official Xbox Wireless Adapter, or the controller's own 2.4GHz dongle if it has one) — same controller, same buttons, just a different plug — and HOTAS mode, V, and M all work exactly as expected.

Why doesn't PlayStation Bluetooth rumble/light work?

It's not broken — nobody has cracked this. When a PS4/PS5 controller connects over a USB cable, it accepts vibration and light-color commands using a simple, well-understood method. Over Bluetooth, Sony uses a different, much stricter method that basically no software outside of an actual PlayStation console has ever gotten working reliably — including big well-known controller tools that have been trying for years. We tested it thoroughly (including trying a second, different Bluetooth adapter) and confirmed the same result every serious attempt online has run into. Moving and pressing buttons over Bluetooth is completely unaffected — only vibration and the light color are impacted.

Head tracking in one minute

Press H in the program window, pick your webcam, pick your game. That's the setup, and there's nothing to install. Then start the game, switch to HOTAS mode and turn your head. The dot in the HEAD box shows where you're pointing. It only works in the game you picked, and only in games where Left Alt + mouse is free look. To use it in another game, press H again, then G.
Anti-cheat notice. Head tracking sends your head movement to the game as mouse movement from software, constantly, while it's on. Some anti-cheat studies how players use the mouse and keyboard, and could treat that as suspicious. One player using a head tracker has reported a ban for hacking, and the game studio's CEO said its detection may have seen it as inhuman mouse movement. There's no official rule or outcome yet, so nobody can promise it's safe. Use it at your own risk.

Reading the screen: right vs. wrong

The top banner and the two INPUT/OUTPUT boxes are the whole story — glance at those first any time something feels off.

✓ Everything's fine

  • Banner reads NORMAL MODE or HOTAS — colored teal, purple, or green (never orange or red)
  • Controller: line names your actual controller (e.g. "PlayStation 5 controller (DualSense)")
  • Both INPUT and OUTPUT boxes show a real type — PS, XBOX, or HOTAS (never blank dashes)
  • Sticks/bars/buttons on screen move the instant you touch the real controller
This is your green light — safe to start the game.

✗ Something's wrong

  • "NOT READY — waiting for a controller..." (orange/red banner)
    Fix: turn the controller on / plug it in. It's picked up automatically — no restart needed. Don't start your game until this clears.
  • "MODE UNKNOWN — press Ctrl+Alt+H once to set it" (red banner)
    Fix: press Ctrl+Alt+H once to choose Normal or HOTAS mode.
  • OUTPUT box shows "----"
    Fix: no virtual controller made yet — set the mode (above) first; check the log file if it still doesn't clear.
  • "This window is too short to show the dashboard..."
    Fix: maximize/enlarge the window, or shrink the font — it fixes itself automatically once there's room.
  • The Battery line turns red
    Fix: the battery is low. Charge the controller.

Two more live indicators worth knowing:

| PS || XBOX |

  • The face buttons light up their real-life color when pressed (PlayStation Triangle/Square/Cross/Circle or Xbox Y/X/A/B) — unpressed buttons stay plain gray. If a button never lights up, that specific button isn't registering.
  • Banner color meanings in full: teal = Normal mode, output matches your real controller type (PS→PS or Xbox→Xbox); purple = Normal mode but output is set to the other type on purpose (e.g. real PS controller showing up as Xbox — this is fine if you did it with V); green = HOTAS mode; yellow = free look, you're looking around; magenta = free look, camera locked; orange/red = mode not chosen yet or no controller found, see the table above.

Something not working?

Every run writes a plain-text log file next to the program (driver_install_log.txt). If anything looks wrong, that file has the details — send it along if you're asking for help troubleshooting. There's also an Uninstall.bat included that cleanly removes everything the program installed, if you ever want to fully undo it. Head tracking installs nothing: it lives in the head_tracker folder beside the program, so deleting that folder removes it.
